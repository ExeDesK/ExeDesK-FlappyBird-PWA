Lecture des métriques

Les compteurs journaliers sont conservés même lorsque les tickets détaillés sont purgés. Le taux de vérification compare les runs résolues dans la période aux tickets émis dans cette même période : une soumission différée peut donc légèrement décaler le ratio entre deux plages.
