Lecture des métriques

Les compteurs journaliers sont conservés même lorsque les tickets détaillés sont purgés. Le taux de vérification d'une période compare les runs résolues pendant cette période aux tickets émis pendant cette même période : une soumission différée peut donc légèrement décaler le ratio entre deux fenêtres.
